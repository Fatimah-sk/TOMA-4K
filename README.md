# 🎬 TOMA 4K
A movie and TV series website built with HTML and CSS, featuring a dark-themed interface for exploring entertainment content.

## ✨ Features
- Dedicated movie and TV series pages
- Movie and series collections
- Navigation between multiple pages
- About Us and Contact Us pages
- Dark-themed design
